# 设计目标与最终验收标准

Human Touch 是 Agent 做出的界面的最后一公里精调层。本文档定义它要达成的目标，以及判定达成与否的可量化标准。规格（`.scratch/<功能>/spec.md`）中的成功标准以本文档为准。

## 差异化：插件结构上做不到的三件事

Chrome 插件与 DevTools 类工具只看得到网页元素、说 CSS 语言、交出一段文字就结束。Human Touch 装在项目里，因此能做到：

1. **懂代码**：理解组件、使用处、实例、推广与设计变量。
2. **能活渲染组件**：通过开发服务器加载组件源码模块，在组件沙盒中浏览状态、props 组合与动效（第二版，ADR 0007）。
3. **闭环可核对**：Agent 交回的每一条改动都在真实页面上核对（ADR 0006）。

## 判定题（Focus）

每个功能都要回答：**这个功能，是否帮助设计师和 Agent 一起把界面细节调对？**

功能本身不必是细粒度调节；只要它让设计师与 Agent 更好地完成细节调整（例如用生成说明给 Agent 一个工作目标），就应当保留。答不上来的功能应考虑砍掉。

## 度量

声称让编辑层更快、更稳、更好用的改动，ticket 里要写明对应的指标、改动前的基线和目标，做完在 Comments 里记下前后数字。测不出收益、或让别的指标变差的改动，考虑撤回。真实 Agent 的数字只拿同一 Agent、同一模型的比较。

## 目标与指标

### Light：接入轻、落地快

| 指标 | 标准 |
|---|---|
| 从 Agent 收到 Guide 到切换按钮出现 | ≤ 60 秒，全程无需人工介入 |
| 安装改动用户源码 | ≤ 2 处（构建配置 1 行 + 挂载 1 行） |
| 首次安装成功率 | Claude Code、Codex、Cursor 各 10 个全新项目，100% 成功 |
| 页面加载时编辑层体积 | 切换按钮 ≤ 10KB；其余在第一次进入编辑模式时加载 |
| 正式构建 | 编辑层代码 0 字节 |
| Agent 落地每条改动 | 平均 ≤ 3 次工具调用，0 次全仓搜索 |

### Flex：像 Framer 一样灵活

| 指标 | 标准 |
|---|---|
| Figma 常用操作覆盖率（以约 40 项的常用操作清单为准） | 第一版 ≥ 90%；第二版（加入状态、变体、动效）≥ 95% |
| 进入编辑模式 | ≤ 150ms |
| 改数值到画面变化 | ≤ 2 帧（33ms；2026-10-30 起，此前为 ≤ 1 帧） |
| 拖拽 | 5000 个元素的页面上保持 60fps |
| 浏览一个组件的全部变体（第二版） | ≤ 1 次点击 |

### Faithful：所见即所落

| 指标 | 标准 |
|---|---|
| 1:1 落地率 | ≥ 95%，以 `done` 核对结果为准，不以 Agent 自报为准 |
| 虚假的 ✓（报告已落地，但页面上没生效，或者改到了作用范围以外） | 0 |
| 设计变量使用率（存在匹配的设计变量时，落地代码引用变量而非写死数值） | ≥ 90% |

### Reversible：零风险

| 指标 | 标准 |
|---|---|
| 撤销一轮 | 任何一轮都能 100% 撤销 |
| 卸载 | `remove` 一条命令，执行后 git diff 为空 |

### Robust：落地不靠 Agent 自觉

Agent 不一定照 Skill 走流程（ADR 0013）。下面的指标用落地流程的测量台测：脚本扮演 Agent 的剧本测机制，真实 Agent 跑标准场景测速度。

| 指标 | 标准 |
|---|---|
| 核对覆盖率：页面能核对的改动，一轮结束前拿到核对结果的比例 | 100%，不论 Agent 是否运行 `done` |
| 进度准确：一轮结束时，进度环显示的条数与页面实际显示的条数之差 | 0 |
| 设计师结束一轮时，没落地的改动留到下一轮 | 100% |
| Agent 停住后，切换按钮出现提示 | 停住后不超过阈值 + 5 秒；Agent 正常工作时误报 0 次 |
| 编辑模式中没认领却在改代码 | 没认领的落地 100% 自动认领；页面不变的代码改动 0 次提示、误认领 0 次（画布上有新建图层时也一样） |
| 认领期间页面核对的代价，和编辑模式中没认领时判断页面有没有变的代价（约 5000 个元素的页面，每次热更新） | 不出现 long task |
| 整轮落地用时（从 `claim` 到 `finish`，按改动条数折算） | 不高于测量台测出的基线；具体目标随基线定 |
| Agent 每轮读入的字数（Skill 与 `claim` 的输出） | 同上 |
