# 设计目标与最终验收标准

Vernier Kit 是 Agent 做出的界面的最后一公里精调层。本文档定义它要达成的目标，以及判定达成与否的可量化标准。规格（`.scratch/<功能>/spec.md`）中的成功标准以本文档为准。

## 差异化：插件结构上做不到的三件事

Chrome 插件与 DevTools 类工具只看得到网页元素、说 CSS 语言、交出一段文字就结束。Vernier 装在项目里，因此能做到：

1. **懂代码**：理解组件、使用处、实例、推广与设计变量。
2. **能活渲染组件**：通过开发服务器加载组件源码模块，在组件沙盒中浏览状态、props 组合与动效（第二版，ADR 0007）。
3. **闭环可核对**：Agent 交回的每一条改动都在真实页面上核对（ADR 0006）。

## 判定题（Focus）

每个功能都要回答：**这个功能，是否帮助设计师和 Agent 一起把界面细节调对？**

功能本身不必是细粒度调节；只要它让设计师与 Agent 更好地完成细节调整（例如用生成说明给 Agent 一个工作目标），就应当保留。答不上来的功能应考虑砍掉。

## 目标与指标

### Light：接入轻、落地快

| 指标 | 标准 |
|---|---|
| 从 Agent 收到 Guide 到切换按钮出现 | ≤ 60 秒，全程无需人工介入 |
| 安装改动用户源码 | ≤ 2 处（构建配置 1 行 + 挂载 1 行） |
| 首次安装成功率 | Claude Code、Codex、Cursor 各 10 个全新项目，100% 成功 |
| 页面加载时编辑层体积 | 切换按钮 ≤ 10KB；其余在第一次进入编辑模式时加载 |
| 正式构建 | 编辑层代码 0 字节 |
| Agent 落地每条改动 | 平均 ≤ 3 次工具调用，0 次全仓搜索 |

### Flex：像 Framer 一样灵活

| 指标 | 标准 |
|---|---|
| Figma 常用操作覆盖率（以约 40 项的常用操作清单为准） | 第一版 ≥ 90%；第二版（加入状态、变体、动效）≥ 95% |
| 进入编辑模式 | ≤ 150ms |
| 改数值到画面变化 | ≤ 2 帧（33ms；2026-10-30 起，此前为 ≤ 1 帧） |
| 拖拽 | 5000 个元素的页面上保持 60fps |
| 浏览一个组件的全部变体（第二版） | ≤ 1 次点击 |

### Faithful：所见即所落

| 指标 | 标准 |
|---|---|
| 1:1 落地率 | ≥ 95%，以 `done` 核对结果为准，不以 Agent 自报为准 |
| 虚假的 ✓（报告已落地但页面上未生效） | 0 |
| 设计变量使用率（存在匹配的设计变量时，落地代码引用变量而非写死数值） | ≥ 90% |

### Reversible：零风险

| 指标 | 标准 |
|---|---|
| 撤销一轮 | 任何一轮都能 100% 撤销 |
| 卸载 | `remove` 一条命令，执行后 git diff 为空 |
