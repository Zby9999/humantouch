# Agent 落地期间暂停编辑

没有发送按钮，设计师随时可能在 Agent 改代码时继续编辑；而编辑模式里的画布是旧页面的副本，代码一改就过期，两边会冲突。因此 Agent 开工时先认领改动单。编辑层察觉到认领后，自动收起成切换按钮，并在落地完成前禁用它。按钮外圈的进度环随 Agent 完成的改动逐渐长满，完成后页面热更新为新样子，按钮恢复可用。如果 Agent 中途中断导致一直锁定，设计师可以手动解锁。

## Considered Options

- **落地期间照常编辑**，新改动记入下一轮：画布可能已和代码不一致，出现冲突时设计师难以理解发生了什么。已否决。

## Consequences

- 进度环依赖 Agent 按 Skill 的要求，每落地一条改动就更新一次进度；Agent 不照做时，进度环会停住，直到落地完成。ADR 0013 起改为按页面核对算进度，手动结束一轮时没落地的改动留到下一轮。
- ticket 78 起，锁不只靠 `claim` 触发：Agent 没认领就落地，编辑模式中页面看到画布上的某条改动显示了出来，就替它认领，同样收起、锁定（ADR 0013）。
