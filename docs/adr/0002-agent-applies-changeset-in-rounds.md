# 改动由 Agent 按轮落地，编辑层不直接改源码

编辑层只负责实时预览和记录改动单；设计师让本地的 Agent 去落地时，Agent 把改动单写进源码，页面刷新为真实结果，一轮结束。这样不用为每种技术栈写源码改写器，能兼容任何 Agent，也保证每轮结束时页面就是代码的真实样子。

## Considered Options

- **实时同步**（每次改动都让 Agent 立刻改代码）：Agent 每次耗时数秒到数十秒，连续编辑时预览与代码结果会互相打架，且只适用于能常驻后台的 Agent。已否决。
- **编辑层直接改源码**（Onlook 的做法）：需要绑定技术栈，并往用户源码中注入标记。第一版不做；改动单的数据结构要为日后"简单改动由编辑层直接写入"留出升级空间。
