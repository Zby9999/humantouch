# 挪出画布的图层跨轮次保留

设计师可以把图层从画布里拖到画布之外的空白处，像在 Framer、Figma 中那样把元素"放一边"，想清楚再放回。这些图层不属于任何一轮：落地、刷新、重新冻结都不会清掉它们，只有设计师手动删除或运行 `remove` 时才清除。这是 ADR 0001"一轮只对应一张画布"的例外。

挪出画布在页面上等于删除：Agent 落地时从源码中删掉它。为了日后能原样放回，挪出时保存两样东西：固化了全部样式的外观（原来的类和样式规则之后可能已不存在），以及它当时的源码片段与位置。拖回画布时是一次插入，改动说明附上源码片段，由 Agent 放回。图层在画布外时可以照常编辑，但不产生改动；拖回时这些编辑作为插入的一部分写进改动单。画布外的图层不单独命名，在图层树中与画布并列显示，与 Framer 一致。

## Considered Options

- **挪出画布不影响代码，画布外只放副本**：与"挪出"的直觉不符，设计师还得再删一次原图层。已否决。
- **画布外的图层随一轮结束清除**：设计师放一边的东西会在落地后消失，失去"暂存"的意义。已否决。
