# 鼠标按着时，键不改画布、改动单和历史

鼠标按着、还没松开时，能改画布、改动单或撤销历史的键都不起作用，按下去什么也不发生；编辑层的键里能用的只有挪动视角的键（空格平移、⇧1 看全部视图）、Esc 和修饰键本身，浏览器自己的快捷键（编辑层不用的 ⌘ 组合：⌘R、⌘F、⌘L、⌘+ 等，以及编辑层用到的字母配上它不用的修饰键，如 ⌘G、Mac 上的 ⌘Y、⌘⇧C、⌘⇧V）照常。"按着"指四种会随指针移动而改动的操作：在画布上按住图层（从按下起算，没移动满 3px 也算，到松手、按 Esc 取消拖拽或指针被取消为止）、在数值图标上拖、拖渐变色标、用 T / F 工具画图层。设计师 2026-10-30 定（ticket 61 只拦撤销和重做，ticket 62 推广到所有改动的键和所有这几种操作）。

这几种操作在松手之前都还没做完：拖拽中让位和被拖图层的样式是临时的，松手或取消时整条 style 属性还原成按下时的样子（ADR 0011）；拖数值和拖色标每一步都按"连续"接进同一步撤销，自己记着值和色标序号，下一次移动接着写；画图层到松手才按当时的画布找位置新建。中途按一个改动的键，就是在一个没做完的操作底下改画布：⌘D 复制出的副本带走了拖拽用的行内样式，Delete 删掉被拖图层后松手它又出现，撤销被让位还原盖掉，拖数值时撤销的值在下一次移动又被写回去、撤销顺序乱掉，撤销改了色标数量后拖的变成另一个色标。与其逐个修补每个键和每种操作的组合，不如规定按着时不改。

- 按着时，输入框里的键照常打字（打出的字不算改动），但输入框不再拿它做别的：回车不提交，方向键不加减数值，色标上的 Delete 和方向键不删、不挪。输入框里还有没提交的文字时，⌘Z 仍归输入框自己（ticket 61）。
- 编辑层自己的键里，既不改画布也不动视角的也一并忽略：⌘C（拖拽中复制会记下被拖、让位后的位置）、T / F / V 切换工具（会改变画图层时松手做出的东西，或在松手后才显现）、焦点所在按钮上的回车（切换模式、开关面板会打断按着的操作）、Tab（焦点离开输入框会提交输入的值）。编辑层要用的 ⌘ 组合（⌘C、⌘X、⌘V、⌘D、⌘⇧G、⌘Z、⇧⌘Z、Ctrl+Y，ticket 117 起还有复制、粘贴样式的 ⌥⌘C、⌥⌘V；⌘ 和 Ctrl 在任何系统上都一样，带 ⌥ 的只有这两个）连浏览器的默认动作也拦下，例如 ⌘D 不会弹出加书签。按字母、修饰键整个组合比对，和编辑层实际绑定的键是同一个判断（`editorCommand`）：⌘Y 不是编辑层的键（Mac 上的重做是 ⇧⌘Z），按着时照常打开浏览器的历史记录；Ctrl+Y 是重做，按着时拦下。最后 review 修正（2026-10-30）改正了这份名单：原来写的是 ⌘Y，代码也只比对字母，⌘G、⌘Y、⌘⇧C、⌘⇧V 这些浏览器的快捷键按着时也被拦了。
- 松开的键（keyup）照常，按着的修饰键松开也照常。

## Considered Options

- **只拦撤销和重做**（ticket 61 的做法）：其他键的问题仍在，设计师决定推广（2026-10-30）。
- **按键时先结束（取消或提交）按着的操作，再执行这个键**：设计师手上还按着鼠标，操作却已经结束，松手时什么也不发生，和预期不符；结束拖拽本身也要还原让位、改动单记一步，和这个键的效果交织。没有采用。
- **在编辑器层面拒绝按着时的改动，而不是在键上拦**：按着画布时，正在输入的输入框失去焦点会提交输入的值，这是按下时就发生、在操作开始之前的正常改动，不应该被拒绝；拖拽本身松手时的那一步也要放过。分不清是哪一种，所以在键上拦。
- **按着时只拦已知的改动键**（逐个列出 ⌘D、Delete 等）：以后加的改动快捷键要记得也加进来，漏一个就会出同样的问题。改为只放行挪动视角的键、Esc 和修饰键，其余一律忽略；只有带 ⌘ 的键按名单分开编辑层的和浏览器的，因为浏览器的快捷键无害，不该被拦。
- **连浏览器的快捷键也一起拦下**：规则更简单，但刷新、查找、缩放网页这些和画布无关的操作在按着时也没了，设计师没有要求。没有采用。

## Consequences

- 加新的快捷键时，不带 ⌘ 的不用另外处理按着的情况：除非它是挪动视角的键，按着时它自动不起作用。带 ⌘ 的要加进 `editorCommand`（Shell 也按它执行这些键），否则按着时它被当成浏览器的快捷键放过去：浏览器的默认动作不拦，元素上的处理也照常收到它。要让某个新键在按着时也能用，就要加进放行的名单，并想清楚它会不会动到没做完的操作。
- 窗口上新加的键盘监听要自己检查 `pointerHeld()`：拦键时的 `stopPropagation` 挡得住输入框、按钮上的处理，挡不住同在窗口上的其他监听。
- 加新的"按着拖"的操作时，要在按下时登记、松开时结束（`holdPointer`），否则这期间的键不受这条规则约束。
- 正在文字图层里打字时，键盘事件在视图自己的文档里，不经过编辑层的键盘处理；这里另外拦下按着时的回车。
- 拖控制点改尺寸（ticket 69，2026-10-31）是第五种"按着"的操作：从按下控制点起（没移动满 3px 也算），到松手、按 Esc 取消或指针被取消为止。它每一步都已经改在画布上，按 Esc 时整次改尺寸被撤回、不留作重做（`Editor.takeBack`）；途中按下或松开 ⌘、⇧、⌥ 立即按新的修饰键重算。
