# 组件沙盒：在冻结画布之外活渲染单个组件

调整状态（悬停、按下、聚焦）、浏览 props 组合（像 Figma variants 一样）、调整并回放动效，都需要能重新渲染的组件，而 ADR 0001 的画布是冻结的静态副本。我们不推翻 ADR 0001，而是增加一个兄弟界面：组件沙盒。设计师在画布上选中一个组件时，旁边出现一个入口按钮（Framer 式），点击进入沙盒；编辑层通过开发服务器加载这个组件的源码模块，在隔离环境中活渲染它，平铺显示它的各个状态与 props 组合。这是 Chrome 插件结构上做不到的事（插件拿不到项目的源码模块），也是 Vernier 的核心差异之一。计划在第二版实现，第一版不动。

## Considered Options

- **让画布本身变成活的**：回到 ADR 0001 否决的路线，结构编辑会和 React 打架。已否决。
- **只在冻结画布上模拟状态**（把 `:hover` 等规则改写成可切换的类）：能看状态，但看不到 props 组合，也无法回放动效。只作为沙盒内的实现手段之一，不单独成为方案。

## Consequences

- Next.js 中，纯展示型的组件即使没有标 `use client` 也能在沙盒中渲染；`async` 的服务端组件和引用了服务端专用模块的组件不能进入沙盒（实现时需验证）。
