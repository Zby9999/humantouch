# 路线图

记录已承诺、但不在第一版范围内的能力。

## 第一版范围（已定）

- 框架：React + Vite、Next.js（App Router）
- 样式：Tailwind、普通 CSS / CSS Modules
- 界面语言：仅英文

## 第一版之后（已承诺）

- **断点编辑（Framer 式）**：按画布宽度区分改动，例如"只在手机尺寸下生效"。第一版的改动对所有屏幕宽度生效，编辑层只显示当前画布宽度。
- **单个实例的覆盖（Override）**：只修改某一个实例，而不是同源的全部实例。
- **组件沙盒（第二版核心，见 ADR 0007）**：选中组件时旁边出现入口按钮，进入后活渲染该组件，浏览状态（悬停、按下、聚焦等）与 props 组合（像 Figma variants），并调整、回放动效。
- **约束 / 钉住（Pin）**：与断点编辑一起做。
- **图片**：插入、替换图片。第一版需要换图时，用 Frame 加生成说明交给 Agent。
- **编辑层直接写入简单改动**：颜色、间距、文字这类简单改动由编辑层直接写进源码、立即生效；结构性改动仍交给 Agent（见 ADR 0002）。

## 待评估

- 更多框架：Vue、Svelte
- CSS-in-JS：styled-components、Emotion 等
- 中文界面
- **改动单附带截图**：第一版不带（浏览器内截图不准、容易让 Agent 按像素拼而不是按意图写）。若在 Claude Code / Codex / Cursor 测试中发现 Agent 常误解布局类改动，再加回。
