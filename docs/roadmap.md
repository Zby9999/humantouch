# 路线图

记录已承诺、但不在第一版范围内的能力。

## 第一版范围（已定）

- 框架：React + Vite、Next.js（App Router）
- 样式：Tailwind、普通 CSS / CSS Modules
- 界面语言：仅英文

## 第一版之后（已承诺）

- **单个实例的覆盖（Override）**：只修改某一个实例，而不是同源的全部实例。已开 ticket 114（2026-11-09），发布以后做。
- **组件沙盒（第二版核心，见 ADR 0007）**：选中组件时旁边出现入口按钮，进入后活渲染该组件，浏览状态（悬停、按下、聚焦等）与 props 组合（像 Figma variants），并调整、回放动效。
- **约束 / 钉住（Pin）**：自由定位图层随父容器尺寸变化的方式。断点编辑已进入第一版（ADR 0008），钉住仍在其后。已开 ticket 113（2026-11-09，在面板里设定位方式，含 Left & Right），发布以后做；Figma 的 Scale（按比例）仍不做。
- **图片**：插入、替换图片。第一版需要换图时，用 Frame 加生成说明交给 Agent。已开 ticket 111（替换）、112（插入）（2026-11-09），发布以后做。
- **编辑层直接写入简单改动**：颜色、间距、文字这类简单改动由编辑层直接写进源码、立即生效；结构性改动仍交给 Agent（见 ADR 0002）。已定 ADR 0015（设计师按改动列表里的按钮才写，只写写死在图层自己身上的值），开 ticket 115、116（2026-11-09），发布以后做。
