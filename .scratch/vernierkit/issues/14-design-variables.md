# 14: 设计变量

**What to build:** 本机服务读取项目中的设计变量（CSS 变量、Tailwind v4 主题、Tailwind v3 配置），属性面板按颜色、间距、圆角、字号、阴影分组显示；每个可用变量的输入框旁都有变量选择器。设计师选用变量后，改动单与改动说明记录变量名，Skill 指示 Agent 引用变量而不是写死数值。读不到变量时只显示数值输入。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

**Blocked by:** 10, 11, 12, 13

**Status:** ready-for-agent

- [ ] 三种来源的变量都能被读出并正确分组
- [ ] 布局、填充、描边、圆角、效果、文字中所有适用的输入框都提供变量选择器
- [ ] 选用变量后画布立即生效，改动说明中写明变量名
- [ ] Skill 中补充优先引用变量的规则
- [ ] 没有设计变量的项目中面板正常工作

## Comments

**补充（2026-10-23，来自完整一轮验证）**

Agent 落地时发现：设计师输入的精确颜色很少等于 Tailwind v4 的现成类（它的色板是 oklch），Skill 又没说近似值算不算"有合适的类"，Agent 只能自己判断。决定：变量只按精确相等判断，不让 Agent 判断近似。

- 设计师选用了变量：改动单记变量名。
- 自由输入的值：编辑层检查它是否恰好等于某个变量（换算到同一色彩空间后比较），等于就写明变量名，否则在改动说明中写明"没有对应变量，用精确值"。
- Skill 同步：有变量名就引用变量；写明没有对应变量时用精确值（Tailwind 用任意值），不找近似的类。
