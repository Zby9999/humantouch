# 14: 设计变量

**What to build:** 本机服务读取项目中的设计变量（CSS 变量、Tailwind v4 主题、Tailwind v3 配置），属性面板按颜色、间距、圆角、字号、阴影分组显示；每个可用变量的输入框旁都有变量选择器。设计师选用变量后，改动单与改动说明记录变量名，Skill 指示 Agent 引用变量而不是写死数值。读不到变量时只显示数值输入。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

- [ ] 布局、填充、描边、圆角、效果、文字中所有适用的输入框都提供变量选择器
- [ ] 选用变量后画布立即生效，改动说明中写明变量名
