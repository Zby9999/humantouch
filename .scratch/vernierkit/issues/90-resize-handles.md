# 90: 在画布上拖控制点改尺寸

**What to build:** 选中一个图层时，选中框的四角和四边出现控制点，像 Figma 一样直接拖着改尺寸：拖角同时改宽和高，拖边只改一个方向；按住 ⇧ 保持宽高比例，按住 ⌥ 从中心向四周改。拖哪个方向，那个方向就变成 Fixed（原来是 Hug 或 Fill 的也一样）；自由定位的图层拖左边或上边时，X / Y 跟着变，对边留在原处；文字图层拖宽度后变成固定宽度、高度随文字。拖的时候吸附到旁边图层和容器的边缘、中线，旁边显示 W × H，按住 ⌘ 暂时不吸附。一次拖拽是一步撤销，进改动单的是设计语言的尺寸，和在属性面板里改宽高一样。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（视图与断点见 ADR 0008，旁边视图的跟随见 ADR 0011，按着鼠标时的按键见 ADR 0012）。

**Blocked by:** 22，以及编辑层线的 61、62（按着鼠标时撤销和按键不改画布）

**Status:** ready-for-agent

- [ ] 选中单个图层时显示四角与四边的控制点；拖角改宽高，拖边改一个方向；⇧ 保持比例，⌥ 从中心改
- [ ] 拖过的方向变成 Fixed，属性面板随之显示；自由定位的图层拖左边或上边时 X / Y 跟着变，对边不动；拖到最小、最大尺寸时停在边界上
- [ ] 文字图层拖宽度后为固定宽度、高度随文字；锁定图层只改外部尺寸
- [ ] 拖的时候吸附到兄弟图层与容器的边缘、中线并显示参考线（与 16 一致），旁边显示 W × H；按住 ⌘ 时不吸附
- [ ] 在平板、手机或其他非桌面视图里拖，只在那个断点生效，行上出现断点标记（57）；在桌面视图里拖作用于所有断点
- [ ] 一次拖拽是一步撤销；按 Esc 取消时回到按下前的尺寸；按着时其他按键按编辑层线 62 的规则处理
- [ ] 改动单记为尺寸改动，Agent 落地后 `done` 能在页面上核对
- [ ] 多选时不显示控制点（多选一起改尺寸要怎样，留给设计师另定）
- [ ] 度量：约 5000 个元素、三个视图的大页面上拖控制点，达到 22 的拖拽标准（帧间隔 p95 ≤ 20.8ms，迟到的帧 < 5%），headless 数字作参考，有窗口 Chrome 的验收数字等设计师同意后再跑；进入编辑模式时间与切换按钮体积不变差；前后数字记在 Comments
- [ ] spec 补上对应的用户故事与交互说明

## 背景

- 2026-10-30 用户发现：现在改尺寸只能在属性面板的 W / H 里改，画布上的选中框没有可拖的控制点；只有用 F / T 新画图层时能拖出尺寸。这是 Figma、Framer 里最常用的操作之一。
- 用户同意行为默认照 Figma 来。
- 和编辑层线正在改的画布拖拽、吸附、按着鼠标时的按键规则重叠很多，等那条线（22、61、62）合回 main 后再做。
