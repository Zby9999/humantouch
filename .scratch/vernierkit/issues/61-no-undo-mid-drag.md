# 61: 拖拽中 ⌘Z 不起作用

**What to build:** 在画布上拖拽图层、还没松手时，撤销和重做的快捷键（⌘Z、⌘⇧Z，以及代码里已有的其他重做快捷键：其他系统上的 Ctrl+Z、Ctrl+⇧Z、Ctrl+Y）不起作用：按下去什么也不发生，改动单、画布、Layers 都不变。松手或按 Esc 取消拖拽之后，撤销和重做照常可用。被拖的图层照旧在三个视图里实时跟着指针走，让位照旧按 ADR 0011，这些都不改。在任何一个视图里拖、拖画布外的图层，都一样。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（拖拽中的让位见 ADR 0011，画布外的图层见 ADR 0009）。

**Blocked by:** None

**Status:** ready-for-agent

- [ ] 在桌面视图和旁边任一视图里拖拽图层，松手前按 ⌘Z 或 ⌘⇧Z，改动单、画布、Layers 都不变；松手后，这次拖拽能被一次 ⌘Z 撤销
- [ ] 拖拽中按 ⌘Z 之后再按 Esc，图层回到原处，没有残留的让位 style
- [ ] 拖拽画布外的图层，同样适用
- [ ] 不在拖拽时，撤销和重做的行为不变
- [ ] 范围只限画布上拖拽图层；代码里其他"拖"的操作（拖数值、拖渐变色标等）如有同类问题，只在本 ticket 的 Comments 里列出，不改
- [ ] 全量 typecheck、单测、e2e 通过，测试数量不少于改动前

## 背景

- ticket 22 第六轮发现的问题（见 22 的 Comments"第六轮"的"给设计师的说明和风险"第 2 条）。第六轮起，拖拽中的让位不再写在画布上，而是由 `views.shiftAside` 写到每个视图自己的元素上；松手或按 Esc 取消时，`views.shiftBack()` 把每个元素的整条 style 属性还原成拖拽开始时的样子（ADR 0011"拖拽"一条）。
- 拖拽中按 ⌘Z 以前没有拦，撤销会直接执行。撤销如果改了某个正在让位的元素的 style（例如撤销刚才对它的一次改值），松手或取消时这条 style 会被还原成拖拽开始时的样子，盖掉撤销的结果，画面和改动单对不上。重做同理。
- **设计师的决定（2026-10-30）**：拖拽还没松手时，撤销和重做的快捷键不起作用。松手或按 Esc 取消拖拽之后，撤销照常可用。被拖的图层照旧在三个视图里实时跟着指针走，这一点不改。

## Comments

**实现记录（2026-10-30）**

*做了什么*

1. **撤销、重做的快捷键怎样判断**（`canvas-keys.ts` 的 `historyKey`）：原来写在 `Shell.tsx` 键盘处理里的判断（⌘Z 撤销；⇧⌘Z 重做；其他系统上 Ctrl+Z、Ctrl+⇧Z、Ctrl+Y；输入框里还有没提交的文字时它自己留着 ⌘Z，Design 面板的输入框没在输入时、渐变色标这类 slider 交给编辑器）原样搬进这个函数，另加一条：拖拽还没松手时返回 `held`，Shell 拦下这个键（不再往下传、也不触发浏览器自己的撤销），什么也不做。输入框里正在输入的文字仍自己留着 ⌘Z，拖拽中也一样，不经过编辑器。
2. **拖拽何时算开始、何时算结束**（`CanvasView.tsx`、`Shell.tsx`）：沿用画布上已有的拖拽（`DragSession`）：按下后指针移动超过 `DRAG_THRESHOLD`（3px）才开始，这和 Esc 取消拖拽用的是同一个判断；松手、按 Esc 取消、指针被取消（`pointercancel`）都走 `endDrag`，在那里结束。`CanvasView` 用新的 `onDragging(underWay)` 告诉 Shell，Shell 记在一个 ref 里，撤销键据此判断。没有靠两个窗口级键盘监听的注册先后，谁先收到键都一样。
3. 覆盖到的拖拽：任一视图里拖图层（包括拖到画布外、拖进别的 Stack 或 Frame）、拖画布外的图层（整个拖动，在工作区里换位置或拖回视图）、拖画布外图层里面的图层。被拖的图层照旧在三个视图里跟着指针走，让位照旧按 ADR 0011。
4. **ADR 0011**："拖拽"一条加了一行：拖拽还没松手时撤销、重做的快捷键不起作用，松手或 Esc 之后照常，写明设计师的决定和日期。GLOSSARY 没有改（没有新词）。

*测试*

- 接缝一：`historyKey`（`canvas-keys.browser.test.ts`，6 → 9 条）。拖拽中 ⌘Z、⇧⌘Z、Ctrl+Z、Ctrl+⇧Z、Ctrl+Y 都是 `held`，⌘C 不受影响；不拖拽时 ⌘Z 撤销、⇧⌘Z 和 Ctrl+Y 重做、⌘Y 和 ⌥⌘Z 不是撤销键；正在输入的输入框拖拽中也自己留着 ⌘Z，Design 面板没在输入的输入框、slider 交给编辑器。它测不到的是 Shell 有没有把拖拽状态接上，这由下面的 e2e 测。
- 接缝二：e2e，从界面操作（新加 4 条，都先在没有修正的代码上跑过，确认会失败）：
  - `drag.spec.ts`"while dragging, ⌘Z and ⇧⌘Z do nothing…"：桌面视图里先拖一次再撤销（留下可以重做的一步），再拖、不松手按 ⌘Z、⇧⌘Z：画布结构、改动单（没有改动）、Layers 的行都不变，段落仍在让位、放置线还在；松手后 1 条改动，一次 ⌘Z 回到拖之前。没修正时这里重做直接执行，结构变了。
  - `drag.spec.ts`"⌘Z while dragging, then Esc…"：先删掉标题（一条改动），拖拽中按 ⌘Z，标题仍是删掉的；按 Esc：结构不变，段落的 style 属性和拖之前一样（让位没有残留），按钮没有留下行内样式，改动单仍是 1 条；之后不拖拽时 ⌘Z 照常把标题撤回来。
  - `views.spec.ts`"while dragging in the phone view…"：在手机视图里拖，等三个视图都让位后，分别按 ⌘Z 和 ⇧⌘Z，每按一次都检查三个视图里标题仍是删掉的、段落仍在让位；结构、改动单、Layers 不变。松手后三个视图结构一致、段落的 style 属性和拖之前一样，2 条改动；第一次 ⌘Z 撤回这次拖拽，第二次撤回删除。
  - `off-canvas.spec.ts`"while a layer off the canvas is dragged…"：把标题挪出画布后拖它（整个拖），按 ⌘Z、⇧⌘Z：它仍在画布外，改动单仍是 1 条；按 Esc 后回到原处，没有行内样式。再拖到别处松手，一次 ⌘Z 回到原处、仍在画布外，再一次 ⌘Z 回到画布上。
- "不在拖拽时撤销和重做的行为不变"：`undo.spec.ts` 等原有 e2e 全部通过，上面几条也在拖拽前后检查了照常撤销。

*拖拽中其他快捷键（不在本 ticket 范围，需要设计师另外决定）*

用临时的 e2e 在桌面视图里试过（拖着按钮到段落上方、不松手按键，之后松手；试完删掉了）。设计师这次只定了撤销和重做，所以没改：

1. **⌘D（复制一份）**：拖拽中复制，副本带走了被拖图层的拖拽用行内样式（`pointer-events: none`、`z-index`、`translate`），松手后副本上仍留着这些样式，画面上它停在偏开的位置、点不到。这是实际的残留，比撤销还明显。
2. **Delete / Backspace**：拖拽中删掉了被拖的图层；松手后它又出现在放下的地方，改动单里是 2 条（删除和移动）。
3. **⌘X**：拖拽中剪掉被拖的图层，松手后它不在了，改动单 2 条。
4. **⇧A（做成 Stack）**：拖拽中把被拖的图层包进新的 Stack，松手后不再移动。
5. 方向键微移：拖拽中按下没有看到变化，松手后只有一条移动。
6. ⌘V、⌥⇧A、⌘⇧G 没有试，走的是同一个键盘处理（Shell 里按选中的图层动作），预计也会在拖拽中执行。

*代码里其他"拖"的操作（只列出，没改）*

1. **在数值图标上拖（Scrub）**：拖动中每一步按连续改值记进同一步撤销。拖动中按 ⌘Z 会撤掉这次拖动到目前为止的改动，但下一次指针移动又按拖动自己记着的值写回去，并以"连续"接到撤销历史里，可能和更早的同一属性的那一步合在一起，撤销的顺序和设计师预期的不一样。这里没有让位那样的整条 style 还原，画面和改动单应该一致，但撤销历史可能乱。没有实际验证。
2. **拖渐变色标**：同样按连续改值记，另外拖动中记着色标的序号（`d.index`），拖动中撤销如果改了色标的数量或顺序，后面的移动可能挪的是另一个色标。没有实际验证。
3. **用 T / F 工具画图层**：画的过程中按 ⌘Z 会撤销；松手时才按当时的画布找放的位置并新建，预计不会残留，但画之前按下的那个视图里的东西可能已经被撤销改过。没有实际验证。
4. 平移画布（空格拖、中键拖）只动相机，不涉及撤销。预览模式里拖切换按钮不在编辑模式里，也不涉及。
5. Layers 面板没有拖拽排序；断点没有可以拖的控件。

*其他风险*

- 按下图层、指针还没移动 3px 时（还不算拖拽），⌘Z 照常撤销，和 Esc 在这时选父图层的判断一致。这时撤销如果去掉了按下的图层（例如撤销了它的创建），再移动指针会拖一个已经不在画布上的图层。这是原有的情况，本 ticket 没改；要不要把"按下"也算进拖拽，需要设计师决定。
- `historyKey` 在拖拽中只拦撤销和重做的键；其他键见上。
