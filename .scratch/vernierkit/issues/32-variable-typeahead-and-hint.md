# 32: 设计变量：边输入边找

**What to build:** 设计师在属性面板的输入框里打字时，下拉列表实时过滤出匹配的设计变量（例如输入 pri 出现 primary-500、primary-600），可用键盘选中；输入具体数值且接近某个设计变量时，输入框内安静地提示这个变量，点击即换成变量，不弹窗、不阻止输入。改动说明仍只按精确相等判断变量（见 14 的 Comments）。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] 输入名称片段时下拉列表实时过滤同组变量，键盘上下选择、回车确认
- [ ] 颜色按感知色差很小判定接近；数值按相差 ≤ 2px 且 ≤ 10% 判定接近；阈值集中在一处便于调优
- [ ] 接近提示只在同组变量内出现，点击后输入框变为变量名标签
- [ ] 设计师不采用提示时，改动单记录精确值，改动说明写明没有对应变量
