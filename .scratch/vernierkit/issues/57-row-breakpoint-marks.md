# 57: 属性面板每行的断点标记与重置

**What to build:** 在平板、手机或其他非桌面视图中选中图层时，凡是在当前视图的断点上单独改过的属性，属性面板里它所在的那一行都标出来，并能在这一行上一键重置为继承，与 Framer 一致。现在只有面板顶部的断点区列出这些属性，设计师要在列表和属性行之间来回对照。桌面视图里不显示标记。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（视图与断点见 ADR 0008）。

**Blocked by:** 37、38（都已完成）

**Status:** ready-for-agent

- [ ] 在非桌面视图中，所有能在断点上单独改的属性（包括 Grid 的列数与间距、自由定位的 X / Y、在此断点隐藏），单独改过时所在行都有标记
- [ ] 在行上一键重置为继承：按 38 的拆分规则只清掉当前视图范围内的部分，值回到继承来的值，标记消失；一次撤销恢复
- [ ] 桌面视图里没有标记
- [ ] 顶部的断点区保留还是去掉由实现时判断：保留就与行上的标记始终一致；去掉就把理由写进本 ticket 的 Comments 和 ADR 0008
- [ ] 浏览器测试与 e2e：在平板视图改填充色，该行出现标记；在行上重置，标记消失、值回到桌面视图的值；桌面视图里没有标记
