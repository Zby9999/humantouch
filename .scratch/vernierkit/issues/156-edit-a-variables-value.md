# 156: 直接改设计变量的值：画布上实时全局生效，简单的由编辑层写进源码

**What to build:** 设计师 2026-11-12 看了 Graphical 2.0（graphicalui.com）后提出。它让整套视觉语言里的值实时可改、全局一起变，手感更直觉、更顺滑。我们照自己的原则拿过来：页面原样能改，不先改造项目，落地到项目自己的代码里。排在 115、116 那组，发布后做。

现在设计变量（ticket 14、119）只能绑定到图层的属性上，不能改变量本身的值。要做到：

- **改值**：在设计变量列表里，每个变量的值都能改：颜色用取色器，间距、圆角、字号用数值。
- **实时、全局**：一改，画布和各视图里所有用到这个变量的地方马上一起变。列表上标出它「用在 N 处」，免得设计师不知道这是全局的改动。
- **进改动列表**：一条单独的改动，比如「--color-brand · #2563eb → #7c3aed」。撤销、重做照常。
- **交出去**：
  - **按钮写掉（ADR 0015）**：变量写在 CSS 文件里，值是字面量的，比如 `:root { --brand: #2563eb; }` 或 Tailwind v4 `@theme { --color-brand: … }`，由 115、116 的按钮直接改那一行的值，不经过 Agent。
  - **交给 Agent**：值引用别的变量（`var(--blue-500)`）、写在 Tailwind v3 的 JS 配置里、或从 JS 算出来的。改动说明写清这个变量定义在哪个文件、哪一行。拿不准就交给 Agent。
- **核对（ADR 0016）**：页面上这个变量算出来的值等于改后的值，用到它的图层画出来和画布一样，就算显示了。
- **同一个变量在多处定义时**：比如深色模式里另有一个值，或 `@media` 里有覆盖，这张票只改默认的那个（`:root` 或 `@theme`）。有别处覆盖时，面板上说明一句。按模式各改各的，见 ticket 157。

用词以 GLOSSARY.md 为准，用「设计变量 (Variable)」，不要用 Token、主题值。参考 ticket 14、119、115、116，ADR 0015、0016。
