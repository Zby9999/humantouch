# 21: 撤销、改动列表与放弃

**What to build:** 编辑模式中可用 ⌘Z / ⇧⌘Z 跨图层按时间顺序撤销、重做。点开切换按钮的角标可看到改动列表并逐条撤销；列表中有 Discard all，二次确认后放弃本轮全部改动，下次进入编辑模式重新冻结画布。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

- [ ] 改动列表逐条撤销后画布与改动单一致
- [ ] Discard all 需二次确认，确认后改动单清空、画布丢弃
