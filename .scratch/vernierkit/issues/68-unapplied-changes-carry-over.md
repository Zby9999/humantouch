# 68: 结束一轮时没落地的改动留到下一轮

**What to build:** 设计师结束一轮时（67 的「结束这一轮」或长按手动解锁），已落地的改动照常归档；没落地的（页面没显示、也没 `done` 的）留到下一轮，不再随画布丢掉。下次进入编辑模式，页面按现在的代码重新冻结，这些改动重新应用到新画布上，在改动列表里照常列出，可以继续编辑、撤销或放弃。找不到对应图层的改动在改动列表里标出来，交给设计师处理。下一轮 `claim` 只拿到这些没落地的改动和新改的。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（ADR 0002、0005、0012）。
