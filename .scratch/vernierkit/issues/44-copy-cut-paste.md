# 44: 复制、剪切与粘贴（⌘C / ⌘X / ⌘V）

**What to build:** ⌘C 复制选中的图层，⌘X 剪切，⌘V 粘贴：选中 Stack 或 Frame 时粘贴到其中（Stack 中放在最后，Frame 中放在原来的相对位置），选中其他图层时放在它之后。复制后粘贴是一次复制改动，剪切后粘贴是一次移动，剪切后不粘贴是一次删除。剪贴板只在编辑层内有效，不写系统剪贴板。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

## Comments

**实现记录（2026-10-28）**

- `clipboard.ts` 的 `createClipboard(editor, changes)`，在已有编辑命令上组合：复制后粘贴是 `duplicate`（与 ⌘D 一样，循环实例照常为数据改动）；剪切是 `remove`，粘贴时先撤回那条删除、再 `move`，改动单里只剩一条移动；剪切后粘贴过一次，再粘贴就是复制。每次剪切、每次粘贴各是一步撤销。
- 粘贴到哪：选中 Stack 时放在最后，选中 Frame 时放在图层原来在它自己容器中的位置（X / Y），选中其他图层时放在它之后（所在容器是 Frame 时同样按原来的 X / Y）；什么都没选时，复制放在原图层之后，剪切的图层回到原处。
- 界面：Shell 的快捷键。编辑层里有东西可粘贴时才拦下 ⌘V，⌘C / ⌘X 只在有选中图层时拦下；输入框、对话框以及画布上的文字编辑照常用系统剪贴板。剪贴板不写系统剪贴板。

**已知限制**

- 本轮新建的图层不能剪切（它不在源码里，没有可移动的东西）：可以复制，或直接拖过去。
