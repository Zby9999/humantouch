# 44: 复制、剪切与粘贴（⌘C / ⌘X / ⌘V）

**What to build:** ⌘C 复制选中的图层，⌘X 剪切，⌘V 粘贴：选中 Stack 或 Frame 时粘贴到其中（Stack 中放在最后，Frame 中放在原来的相对位置），选中其他图层时放在它之后。复制后粘贴是一次复制改动，剪切后粘贴是一次移动，剪切后不粘贴是一次删除。剪贴板只在编辑层内有效，不写系统剪贴板。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。
