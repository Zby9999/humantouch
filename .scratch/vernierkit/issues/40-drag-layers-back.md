# 40: 把画布外的图层拖回

**What to build:** 设计师把画布外的图层拖回任一视图中的任意位置（遵循拖拽规则），作为一次插入写进改动单；改动说明附上原来的源码片段、外观与它在画布外做过的编辑，Agent 按片段原样放回（必要时按当前代码调整）。即使原代码已在上一轮被删除也能放回。同一轮内挪出又拖回原位置时，两条改动相互抵消。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（视图与断点见 ADR 0008，挪出画布的图层见 ADR 0009）。

## Comments

实现时的决定（设计师不在，按 spec、ADR 0009 与已有做法取最简单一致的方案，已补进 ADR 0009）：

- 同一轮内挪出、在画布外没编辑过：拖回撤掉那条删除，原图层（类与页面样式都还在）回到画布；拖回原位置两条改动抵消，拖到别处记成一次移动。
- 在画布外编辑过、上一轮挪出、或 ⌥ 挪出的副本：拖回记成一次插入（`putBack`），附源码片段、外观与在画布外的编辑；画布上用固化外观（类不恢复，留在 `data-vk-class`），按计算样式与画布逐层对齐，图层本身整份固定，各视图一致。同一轮内编辑过再拖回时那条删除保留，改动说明让 Agent 移动代码而不是删掉重写。
- 从画布外拖进视图时不让位（只显示落点框与插入线）：从外面进入时让位会让内容从指针下滑走，落点跳动。
- 本地服务保存画布外图层时把源码片段回传给编辑层，拖回后撤销、刷新都不丢片段。
