# 40: 把画布外的图层拖回

**What to build:** 设计师把画布外的图层拖回任一视图中的任意位置（遵循拖拽规则），作为一次插入写进改动单；改动说明附上原来的源码片段、外观与它在画布外做过的编辑，Agent 按片段原样放回（必要时按当前代码调整）。即使原代码已在上一轮被删除也能放回。同一轮内挪出又拖回原位置时，两条改动相互抵消。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（视图与断点见 ADR 0008，挪出画布的图层见 ADR 0009）。

**Blocked by:** 39

**Status:** ready-for-agent

- [ ] 拖回后三个视图同时出现该图层，落在 Stack 中占一个位置，落在空白处为自由定位
- [ ] 改动说明中拖回写成插入，附源码片段、外观与在画布外做过的编辑
- [ ] 上一轮已落地删除的图层，在下一轮拖回后 Agent 能按片段放回
- [ ] 同一轮内挪出又拖回原位置，改动单中不留下这两条改动
- [ ] Skill 补充拖回的落地规则
- [ ] 辅接缝 1 覆盖挪出 / 拖回的抵消规则
