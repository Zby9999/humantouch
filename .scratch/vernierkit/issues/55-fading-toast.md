# 55: 会自动消失的简短提示

**What to build:** 编辑层有一种简短提示：从编辑层窗口底部居中浮出，一行字的深色胶囊，约 3 秒后淡出（样式与时长参照 Figma 的习惯）。描边按 0.5px 取整的提醒改用它显示，不再固定在属性面板里。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

**Blocked by:** 51（已完成）

**Status:** done

- [x] 提示出现在编辑层窗口底部居中，约 3 秒后淡出；鼠标停在上面时不消失
- [x] 新的提示替换旧的，不堆叠
- [x] 读屏软件能读到提示；开了减少动态效果时不做位移动画
- [x] 描边取整的提醒改用这个提示，属性面板里原来那行说明去掉
- [x] 提示放在编辑层的外壳上，不改画布（避免和视图那条线冲突）

## 背景

- 51 的取整提醒沿用了属性面板里现有的说明样式，固定在 Stroke 段末尾，换选中或下一次输入时才消失；编辑层原先没有会自己消失的提示。
- 用户要的是会自动消失的提示。

## Comments

**实现记录（2026-10-29）**

- 新模块 `client/Toast.tsx`：编辑模式外壳上的提示。`Toast` 组件放在外壳里（与工具条同级），`ShowToast` 经 `ToastProvider` / `useToast()` 交给要显示提示的部分；外壳目前只把属性面板包在里面。以后别的简短说明要用，就在外壳里同样包一层，再调用 `useToast()`。不在 `ToastProvider` 里调用时什么都不显示。`CanvasView.tsx`、`edits.ts` 没有改。
- 位置与样式（`styles.ts` 的 `.vk-toasts` / `.vk-toast`）：浮在画布之上，在画布那一栏的底部居中，离底边 16px。外壳的两侧面板各 240px，所以左右各让出 240px；隐藏图层面板时左边不让，播放时两边都不让。胶囊是一行字，深色底 `#1e1e1e`，与切换按钮、改动列表的底色相同，并带同样的描边和阴影。字体沿用外壳的 11px/16px，圆角 8px，与工具条相同。放不下时省略号截断。
- 时长：出现后 3 秒（`TOAST_MS`）淡出，淡入淡出各 180ms（`motion.ts` 的 `TOAST_FADE_MS`）。淡入时从下方 8px 升上来，淡出时沉下去。鼠标停在上面时不计时，正在淡出时也会停下并回到不透明；移开后重新计 3 秒。
- 替换：外壳里同时只有一条提示。新提示在原地换字并重新计时，胶囊不重新淡入，所以拖动数值时一连串提示不会闪。换字时内层 `span` 按提示编号重建，所以即使字相同，读屏也会再读一次。
- 读屏：外层容器一直在，`role="status"`（polite live region），提示的字出现在里面时会被读出。开了减少动态效果时，淡入只改透明度，淡出只过渡透明度，不做位移。
- 描边取整提醒：`StrokeSection` 输入的粗细被取整时，调用 `useToast()` 显示 "Stroke weights go in 0.5px steps: 1.25px is now 1px."。属性面板里原来那行 `vk-layer-note` 说明，以及它的状态（随撤销、换选中、改颜色或线型消失）都去掉了。`vk-layer-note` 样式其他地方还在用，保留。
- 测试（主接缝）：`properties.spec.ts` 改写了 51 的用例：取整时提示的文字，属性面板里不再有这句；输入本来是 0.5 的倍数时不提示。新增一条用例，用 `page.clock` 控制时间：提示在画布区域底部居中；新提示替换旧的且重新计 3 秒；鼠标停在上面 6 秒不消失，移开后约 3 秒消失。`motion.spec.ts` 新增两条：用 CDP 放慢动画，检查淡入中途的透明度与位移；淡出时用 `transitionrun` 记下有哪些属性在过渡。不减少动态效果时透明度与位移都变，减少动态效果时只变透明度。

**已知限制**

- 画布区域的左右边距按外壳两侧面板的 240px 写死在样式里（工具条的 `right: 248px` 同样如此）。面板宽度以后要是能改，这里也得跟着改。
- 读屏是否重读由 live region 的实现决定：同样的字重建 `span` 后，主流读屏会再读一次，但没有在真实读屏软件上验证，测试只确认了 `role="status"`。
- 提示期间如果设计师开始播放，提示会留在全屏画布上直到淡出。
- 撤销不会收回已显示的取整提示，它到时自己淡出。51 的说明会随撤销消失。
- 从页面原有的非 0.5 倍数粗细（如 1.25px）开始按住拖动数值时，每一步都会取整，提示在原地连续换字。
