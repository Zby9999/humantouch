# 121: 生成说明从工具栏写，写完的注释卡放在画布外、用虚线连着图层

**What to build:** 现在写生成说明（Brief）有两个入口：Design 面板最后一节的「Add brief」，和新建 Frame 旁边的弹出框。写完的说明只在图层树和画布上留一个标记，要选中图层才看得到内容。

设计师要换成另一种做法：
- 画布左边的工具栏现在有 Select（V）、Frame（F）、Text（T），再加第 4 个工具 Brief。
- 选中 Brief 工具后点一个图层，就开始给它写生成说明。
- 写完的说明是一张注释卡，放在画布外，也就是三个视图之外的空白处。卡和图层之间画一条虚线，连到图层上离卡最近的那一边的中点。
- 注释多了，卡互相避开，不互相压住，也不挡视图和画布外的图层。
- 面板里的「Add brief」和 Frame 旁边的弹出框都去掉。

给 Agent 的部分不变：生成说明照旧是一条改动（种类「生成说明」），改动说明一字不变。

参考本功能的 spec.md（同目录上一级，「生成说明」「画布外的图层」「视图」，用户故事 69、71a、71b），用词以 GLOSSARY.md 为准（生成说明 Brief、画布外的图层、视图），并遵守 docs/adr/ 中的决策（ADR 0008、0009、0011、0012）。

**Blocked by:** 无

**Status:** ready-for-agent

- [ ] 工具栏第 4 个工具 Brief，和 Frame、Text 一样能按、能用快捷键（建议 B，作为代定），提示写「Brief (B)」。选中它后点一个图层，开始给它写；按 Esc 或点空白处退出，回到 Select。能给哪些图层写，照现在的规则：任意图层，包括在空白处新建的画布外图层，但挪出画布的图层不能写（spec「画布外的图层」）。已经有说明的图层，点它就是打开它的卡来改。
- [ ] 去掉 Design 面板里的「Add brief」一节和新建 Frame 旁边的弹出框。新建 Frame 想交代要生成的内容，就用 Brief 工具点它：Agent 拿到的仍是「带生成说明的新建 Frame」（可配草图），说明逐字不变。
- [ ] 注释卡放在画布外，跟着写它时所在的视图，默认是桌面视图：一条说明一张卡、一条线。卡和画布一起缩放、平移（放在画布上的注释，不是屏幕上固定大小的评论）。虚线连到图层上离卡最近那一边的中点。图层挪动、改尺寸，视图让位（ADR 0011）时，卡和线跟着走。
- [ ] 碰撞：卡不互相压住，不压在任何视图和画布外的图层上，连线尽量不交叉。几十条说明也排得开。摆放规则（放在哪一侧、怎么排开、按图层在视图里的上下顺序排等）作为代定，照 Figma 放在画布上的注释和标注的习惯。
- [ ] 在卡上改字、删掉说明，都是这一条改动的改与撤；⌘Z 一步撤回，⇧⌘Z 重做；按着指针时不起作用（ADR 0012）。图层被删、被挪出画布时，它的卡跟着去掉；撤回删除时卡回来。图层树上的 Brief 标记照旧。
- [ ] 刷新、重新进入编辑模式，卡在原来的位置，按同样的规则排。预览模式里不显示卡和线。落地之后说明照现在的规则归档，卡随之消失。
- [ ] 卡的样子、线的样子、工具栏图标照 Figma 先做一版，之后交给调前端。调前端第 2 轮把 Stack、Grid 两节都改名为「Layout」（还在它的分支上），新测试不要按这些节的名字找元素。
- [ ] 给 Agent 的部分逐字不变：`--dry` 全过（d996f27 起 28 个场景），`--dry --claim-out` 和改前逐字相同，`--scripted` 全过；切换按钮的包逐字节不变。
- [ ] 性能 headless 前后对比（`TK_PERF_HEADLESS=1`）：进入编辑模式不变差（余量只有几毫秒，见 ticket 105；没有说明时什么都不加），拖动、改数值不变差。另加一项：有 20 条说明时拖动图层、缩放画布仍 60fps。
- [ ] e2e 全过；新测试照 ticket 93 的写法；spec 的「生成说明」一节、用户故事 69、71a、71b 照新做法改写。
