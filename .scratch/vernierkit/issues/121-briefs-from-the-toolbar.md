# 121: 生成说明从工具栏写，写完的注释卡放在画布外、用虚线连着图层

**What to build:** 现在写生成说明（Brief）有两个入口：Design 面板最后一节的「Add brief」，和新建 Frame 旁边的弹出框。写完的说明只在图层树和画布上留一个标记，要选中图层才看得到内容。

设计师要换成另一种做法：
- 画布左边的工具栏现在有 Select（V）、Frame（F）、Text（T），再加第 4 个工具 Brief。
- 选中 Brief 工具后点一个图层，就开始给它写生成说明。
- 写完的说明是一张注释卡，放在画布外，也就是三个视图之外的空白处。卡和图层之间画一条虚线，连到图层上离卡最近的那一边的中点。
- 注释多了，卡互相避开，不互相压住，也不挡视图和画布外的图层。
- 面板里的「Add brief」和 Frame 旁边的弹出框都去掉。

给 Agent 的部分不变：生成说明照旧是一条改动（种类「生成说明」），改动说明一字不变。

参考本功能的 spec.md（同目录上一级，「生成说明」「画布外的图层」「视图」，用户故事 69、71a、71b），用词以 GLOSSARY.md 为准（生成说明 Brief、画布外的图层、视图），并遵守 docs/adr/ 中的决策（ADR 0008、0009、0011、0012）。

### 121 做了什么（2026-11-10；起点 431f898a，分支 claude/inspiring-jepsen-5cf2e9）

**做了什么**

- 工具栏第 4 个工具 Brief（图标是原来的便签 `brief`，提示「Brief (B)」，键 B）。拿着它点图层：照点选的规则选中它（⌘ 点最深的），在卡上写，已有说明的就打开它的卡来改；工具一直拿着，Esc 或点视图外的空白处放下、回到 Select。点在挪出画布的图层上什么都不做。点击在松手时才算（按下就开卡，焦点会被随后的 mousedown 抢走）。按着的时候照 ADR 0012 握住指针（`holdPointer`），⌘Z、V 等不起作用；在面板外松手、松手时已经换了工具，都不写。
- 去掉 `BriefSection.tsx`（Design 面板最后一节）、`AboveCanvas.tsx` 里新建 Frame 旁的 `Brief` 弹出框、`BriefMark.tsx`（画布上图层右上角的小标记，卡和线代替了它）。图层树的 Brief 标记照旧。给新建 Frame 写说明也用 Brief 工具点它，照旧走 `editor.setBrief` 的新建 Frame 路径，记在新建那条改动里。
- 卡（`BriefCards.tsx`）：一条说明一张卡，几个实例共用一张（按 `data-tk-layer` 去重）。卡放在一个和舞台同样 transform 的层里，跟画布一起缩放、平移；线是同层里的 SVG，`vector-effect: non-scaling-stroke`，任何缩放都是 1px 虚线，图层那端一个小圆点。卡上写图层名和说明原文，有「Remove brief」；选中图层时卡和线高亮。点卡就在卡上改：离开或 Enter 生效（⇧Enter 换行），Esc 不改，空着离开不记；写、改、拿掉各是一步，⌘Z / ⇧⌘Z 走原来的 `setBrief`。卡上打字时按键是字，不是画布快捷键。
- 摆放（`brief-cards.ts`，纯函数，`test/brief-cards.test.ts` 8 条）：见代定 3。卡的高度只在内容变了时量（拖动、缩放时不量）；每次渲染照图层现在的位置重排，所以图层挪动、改尺寸、视图让位时卡和线跟着走。
- 卡所在的视图记在 localStorage（`03kind:brief-views`，按页面路径、按图层 id），刷新、重新进编辑模式还在原来的视图旁；拿掉说明时清掉那一条（id 之后可能被新图层用上）。
- 打开一张在屏幕外的卡（比如桌面视图左边那一列），画布平移到刚好看得见它；⇧1 把卡也算进视野。
- 图层被删、挪出画布：DOM 里没有它的 `data-tk-brief` 了，卡就没了；撤回就回来。预览模式和全屏预览不画卡。没有说明时 `BriefCards` 不挂载，进入编辑模式那条路上没有加任何东西（原来就有的 `querySelectorAll` 照旧）。

**代定的事（待设计师确认）**

1. 快捷键 B，提示「Brief (B)」，图标沿用原来的便签图标。
2. 工具一直拿着（像 Figma 的评论工具 C），写完一张还能接着点下一个图层；Esc 或点空白处放下。新建 Frame、文字的工具画完就放下，这里不一样。
3. 摆放：最左的视图（桌面视图）的卡放左边，最右的视图的卡放右边，中间的视图（平板）的卡在它上方、标签之上排一行，只有一个视图或画布外的图层时放离图层近的一侧。一侧的卡按图层中线从上到下排（上方那行从左到右），尽量和图层中线对齐，碰到别的卡、视图（连标签）、画布外的图层就往下（往右）让，所以不压、连线不交叉。卡离视图 160px（视图间距的两倍），卡宽 320px，都是画布 px。
4. 线连到图层四边中点里离卡中心最近的那个，卡这头是卡四边中点里离那个点最近的。
5. 能写的图层：照点选规则选中的那个（第一次点选外层，选中后再点往里），⌘ 点最深的；图层树上选中再到画布上点也行。整个页面也能写。挪出画布的不能写（点了没反应，没有提示）。
6. 卡的样子（第一版，交给调前端）：白底，顶上 6px 蓝条，圆角 16px，22px 字，图层名蓝色，右上角 ×；选中或正在写时一圈 3px 蓝边。线是蓝色 4/4 虚线，不选中时 60% 不透明。Brief 工具拿着时光标是 `copy`。
7. 改法：Enter 生效、⇧Enter 换行（像 Figma 评论；原来面板里是 ⌘Enter）。点卡就进入改写。
8. 卡所在的视图记在这台浏览器里，不进改动单（不影响给 Agent 的东西）；换台电脑打开卡都在桌面视图旁。
9. 打开屏幕外的卡时画布会平移过去；进入编辑模式时的镜头不把卡算进去（不碰进入编辑模式那条路）。
