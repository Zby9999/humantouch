# 07: 完整的一轮落地

**What to build:** Agent 按 Skill 认领后逐条落地并汇报进度，最后结束一轮：编辑层在认领时自动收起成切换按钮并锁定，进度环随 `done` 逐渐长满、角标递减，`finish` 后归档并解锁，页面热更新为真实结果。设计师可长按手动解锁；Agent 可用 `last` 取得上一轮改动说明来撤销上一轮。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] `claim` 后编辑层（若处于编辑模式）自动收起为切换按钮，按钮在落地期间不可用
- [ ] 每次 `done <编号>` 后进度环增长、角标减一
- [ ] `finish` 后本轮归档到历史，按钮恢复可用，可开始新一轮
- [ ] 长按切换按钮手动解锁：已完成的改动归档，未完成的改动记入归档，画布丢弃
- [ ] `last` 输出上一轮的改动说明
- [ ] Skill 补全：完整流程（claim → 逐条落地并 done → finish）、固定报告格式（✓ 已落地 / ⚠️ 无法 1:1 落地的改动、原因、实际处理方式）、撤销上一轮的做法
- [ ] 主接缝：端到端测试走通 claim → done → finish 并断言锁定、进度与解锁
