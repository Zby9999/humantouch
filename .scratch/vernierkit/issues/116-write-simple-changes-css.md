# 116: 编辑层直接写进源码：CSS 和 CSS Modules 里的声明

**What to build:** 在 115 的基础上，按钮也写 CSS 的简单改动：普通 CSS 文件或 CSS Modules 里，只有这个图层在用的一条规则中的声明（改值、加上、去掉一条声明）；断点上的改动写进那个断点对应的、项目已有的 `@media` 规则里（没有就交给 Agent）。规则还管着别的元素、来自第三方或全局样式、靠选择器组合才命中的，都交给 Agent（ADR 0015）。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（ADR 0006、0015）和 ticket 115 定下的做法。

**Blocked by:** 115

**Status:** ready-for-agent

- [ ] 「只有这个图层在用」怎么判定（页面上这条规则命中的元素只有它的各个实例；CSS Modules 的类只在这一处 JSX 里用）作为代定，拿不准就交给 Agent
- [ ] 写进 CSS 时只改那一条声明，不重新格式化；设计变量优先（`var(--…)`），照 Agent 的写法规则
- [ ] 写完照 115 的流程核对、归档、能撤回；对不上时不写，留给 Agent
- [ ] Next.js CSS Modules 示例和一个普通 CSS 的页面上各有测试：改颜色、间距、断点上的间距，按按钮，源码对、页面对，`last` 撤回后复原
- [ ] 不按按钮时一切照旧：`--dry` 24/24、`--scripted` 全过，改动说明逐字不变；切换按钮的包逐字节不变
- [ ] 性能 headless 前后对比（`HT_PERF_HEADLESS=1`）：进入编辑模式、改数值不变差
- [ ] e2e 全过；spec、docs/roadmap.md 相应更新
