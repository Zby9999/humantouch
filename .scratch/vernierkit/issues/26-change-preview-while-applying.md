# 26: 落地时撤下改动预览

**What to build:** Agent 落地期间，每 `done` 一条改动，就撤下这条改动的预览，页面显示的是 Agent 写进源码后的真实结果；`finish` 或手动解锁后，页面上不再有任何改动预览。这样改动预览不会掩盖 Agent 没能 1:1 落地的改动。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

**Blocked by:** 25, 07

**Status:** ready-for-agent

- [ ] `done <编号>` 之后，这条改动的预览立即撤下，其他未完成的改动仍在预览中
- [ ] `finish` 后页面上不再有改动预览，页面就是代码的真实样子
- [ ] 手动解锁后，已完成的改动不再预览；未完成的改动随本轮一起归档，也不再预览
- [ ] 主接缝：端到端测试走通 claim → done → finish，断言每一步真实页面上的预览与真实结果
