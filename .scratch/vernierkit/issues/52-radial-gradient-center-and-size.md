# 52: 径向渐变的中心与大小，色标保留原单位

**What to build:** 设计师能在属性面板上看到并修改径向渐变的中心（X、Y）与大小，画布立即生效；页面上用 px 写的色标，在色标条上的位置与页面画出来的一致，写出的样式中仍用 px。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

**Blocked by:** 11（已完成）

**Status:** ready-for-agent

- [ ] 面板显示并可修改径向渐变的中心 X、Y 与大小（横向、纵向半径，两者相等即为圆形），画布立即生效
- [ ] 页面上用关键字写的大小（如 `closest-side`、`farthest-corner`）和用 % 写的中心，没改动时原样保留
- [ ] 线性与径向渐变中用 px 写的色标，在任意形状与中心下在色标条上的位置都正确；画布、参考样式和改动说明中仍用 px；新加的色标用 %
- [ ] 改动说明用设计语言描述径向渐变的中心与大小，不再原样贴出 CSS 的形状文本
- [ ] 画布上的拖拽手柄不在本 ticket 内（要改画布，等视图那条线合并后另开 ticket）

## 背景

- 现在径向渐变的形状与中心按 CSS 文本原样保留，面板无法编辑。
- 色标位置一律存为百分比，px 写的色标按默认椭圆（图层中心、到最远角）的半径换算，形状或中心不同时会算错。例：200×100 的图层，`circle closest-side at 30% 20%` 的半径是 20px，20px 处的色标应是 100%，现在读成约 14%。
- 写出的样式一律用 %，Agent 落地时会把源码里的 px 悄悄改成 %；px 是固定长度，% 随图层缩放，图层尺寸一变渐变就变样。
- 模型以 CSS 能表达的为界：CSS 的径向渐变不能旋转椭圆，不照搬 Figma 的旋转手柄。
