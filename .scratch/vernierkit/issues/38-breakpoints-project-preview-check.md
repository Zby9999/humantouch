# 38: 断点对齐项目、预览与核对

**What to build:** 视图的宽度范围对齐项目已有的断点（从 Tailwind 主题与 CSS 媒体查询读取，读不到时按视图宽度划分），改动说明写出对应的项目断点（例如 Tailwind 的 md:）。改动预览中断点改动以对应的媒体查询注入，真实页面在该宽度下显示改动。`done` 在该断点宽度下的真实页面上核对断点改动（例如在对应宽度的隐藏 iframe 中加载同一页面），读不到时结果为没能核对。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（视图与断点见 ADR 0008，挪出画布的图层见 ADR 0009）。

**Status:** ready-for-agent

- [ ] Tailwind v4、Tailwind v3 与纯 CSS 示例项目中都能读出项目断点，视图宽度范围与之对齐
- [ ] 改动说明中的断点改动写出对应的项目断点
- [ ] 预览模式下把浏览器调到对应宽度，改动预览显示断点改动，其他宽度不显示
- [ ] `done` 断点改动时在该宽度下核对，显示了 / 没有显示 / 没能核对三种结果都有测试覆盖
