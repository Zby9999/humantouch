# 27: 结构类改动的预览

**What to build:** 改动预览覆盖能在真实页面上显示的结构类改动：Stack 内换顺序、同一父容器内改为自由定位、删除。改动预览无法显示的结构类改动——跨容器移动、合成或解散 Stack、新建文字或 Frame、复制——标为"落地后可见"，计入"N 处改动落地后才能看到"的提示。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。改动预览不移动、不新建页面中由 React 管理的元素（ADR 0001）。

**Blocked by:** 25, 15, 17, 19

**Status:** ready-for-agent

- [ ] Stack 内换顺序后，真实页面上的顺序与画布一致，其他图层照常让位
- [ ] 同一父容器内改为自由定位的图层，在真实页面上停在画布上的位置
- [ ] 删除的图层在真实页面上不再显示
- [ ] 无法预览的结构类改动计入"落地后才能看到"的提示
- [ ] 改动预览不改动真实页面的元素结构，页面重新渲染时不报错

## Comments
