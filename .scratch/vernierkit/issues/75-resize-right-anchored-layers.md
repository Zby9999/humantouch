# 75: 按右边或下边定位的自由图层，拖控制点改尺寸时对边也不动

**What to build:** 页面里有些自由定位的图层是按右边或下边摆的（例如 Tailwind 的 `absolute right-2`、`bottom-4`），或者用 `translate(-50%)` 居中。拖它们的右边或下边控制点改尺寸时，现在只写了宽或高，页面仍按右边、下边摆，图层会往左、往上长：拖的边没跟着指针，本该不动的对边反而动了。改后，这类图层和按左边、上边摆的图层一样：拖哪条边，哪条边跟着指针，对边留在原处；改动单写清楚位置，Agent 落地后页面上也是这样。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

## 背景

- 来自 ticket 69 的实现记录（2026-10-31，遗留风险第 1 条）。69 里自由定位的图层拖左边或上边时会同时写 X / Y，这时定位方式也改成按左、上，所以没有问题；只拖右边或下边时 X / Y 的值没变，编辑命令不写它们，页面就仍按原来的右边、下边摆。
- 修法的方向（69 的子 agent 建议）：自由定位的图层改尺寸时，总是写下对边的位置，所以编辑命令要能在值没变时也改定位方式；改动说明里让 Agent 把 `right` / `bottom` 定位改成 `left` / `top`。
- 可选做法：
  1. 改尺寸时一律改成按左边、上边定位（最简单，但会改掉页面原来的定位方式，窗口变宽时图层的位置可能和原来不同）。
  2. 保留原来的定位方式，按右边定位的就改 `right` 的值（窗口变宽时行为不变，但要让编辑层和改动单认识 `right` / `bottom`）。
  3. 不改，只在 spec 里写明这类图层拖右边、下边时会往反方向长。
- 这会改变 Agent 落地后页面的 CSS，以及在属性面板改 W / H 时的结果。画布线指挥在 69 之后开出（2026-10-31），等设计师定要不要做、选哪一种。
