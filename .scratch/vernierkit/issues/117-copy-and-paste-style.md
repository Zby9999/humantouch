# 117: 复制样式、粘贴样式

**What to build:** 编辑层现在能复制、粘贴图层（⌘C、⌘X、⌘V），但不能只复制样式：⌥⌘C、⌥⌘V 现在什么都不做。设计师在 Figma 里常用 Copy properties / Paste properties，把一个图层的样子套到别的图层上。要做到：选中一个图层按 ⌥⌘C 记下它的样式，选中一个或几个图层按 ⌥⌘V，把样式套上去，画布马上变，三个视图都变。

复制哪些照 Figma 的 Copy properties：外观（填色、描边、圆角、效果、不透明度等）和文字样式（字体、字号、字重、行高、字距、文字颜色等）；不含位置、尺寸、Stack / Grid 的布局，也不含文字内容。开线时先核对 Figma 实际复制哪些，有出入的作为代定。每一项粘贴出来都是一条普通的样式改动，和在面板里一项项改一样，Agent 那边没有新东西。

参考本功能的 spec.md（同目录上一级，「属性面板」「合成与解散 Stack」里 ⌘C、⌘V 的规则），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（ADR 0008、0012）。

**Blocked by:** 无（开线时间见「设计师决定」）

**Status:** ready-for-agent

- [ ] 单选一个图层按 ⌥⌘C 记下它的样式（只在编辑层里，和 ⌘C 一样不动系统剪贴板）；选中一个或几个图层按 ⌥⌘V 套上；多选时按 ⌥⌘C 怎么办作为代定（Figma 的做法）
- [ ] 样式用的是设计变量的，粘贴过去还是那个变量，不变成写死的值；从文字图层复制到 Frame、从 Frame 复制到文字图层时，哪几项对得上（例如文字颜色和填色）作为代定，对不上的不套
- [ ] 在平板、手机视图里粘贴只在那个断点生效（ADR 0008），有断点标记；复制时取的是按下 ⌥⌘C 那个视图里显示的样式
- [ ] 粘到实例上照实例的规则：作用于这个使用处的全部实例（不跟随的实例照 ticket 114）；粘到锁定图层上不套
- [ ] 一次粘贴是一步，⌘Z 一步撤回，⇧⌘Z 重做；按着指针时 ⌥⌘C、⌥⌘V 不起作用（ADR 0012，`canvas-keys` 里它们现在是放行的）
- [ ] 改动列表、改动说明和面板里一项项改出来的一样；`done` 照常核对；原来的改动说明逐字不变：`--dry` 24/24、`--scripted` 全过；切换按钮的包逐字节不变
- [ ] 性能 headless 前后对比（`TK_PERF_HEADLESS=1`）：进入编辑模式、改数值不变差；96 个实例的大页面上粘贴一次不比在面板里改一项慢得看得出
