# 25: 改动预览：样式改动显示在真实页面上，并可开关对比

**What to build:** 在预览模式中，真实页面按原比例显示改动单里的样式改动（目前是填充与圆角），页面照常可点、可悬停、动效照常播放，设计师在 Agent 落地前就能试用改动后的效果。切换按钮旁有"改动后 / 现在"开关，用来对比现在的网站。在真实页面上找不到对应元素的改动，提示"N 处改动落地后才能看到"。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。编辑仍发生在画布上（ADR 0001），改动仍由 Agent 落地（ADR 0002）；改动预览只影响显示，不改源码。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 有未落地改动时，预览模式中的真实页面显示这些样式改动，悬停、点击、动效照常可用
- [ ] 改动只作用于对应使用处的实例，同一组件的其他使用处不变
- [ ] React 重新渲染、页面内跳转、新打开的弹窗等新出现的元素上，改动同样生效，不闪现改动前的样子
- [ ] 刷新浏览器后，改动预览照样生效
- [ ] "改动后 / 现在"开关可随时切换，开关状态在刷新后保留
- [ ] 没有源码标记、在真实页面上找不到对应元素的改动，计入"N 处改动落地后才能看到"的提示
- [ ] 改动预览打开时，离开编辑模式不再淡出，直接撤下编辑层；开关停在"现在"时保留淡出
- [ ] 主接缝：在示例项目中编辑后回到预览模式，断言真实页面的计算样式、使用处范围、开关对比与刷新后的表现
