# 20: 作用范围与推广

**What to build:** 修改实例时默认只影响它所在的使用处（同一使用处的实例同步）。图层带有未推广改动时，选中框右上角的选中工具条里出现推广按钮（Promote）；点击后，这个图层上的所有改动一起推广到离它最近的那一层组件，画布上同组件的其他图层立即一起变化，改动说明的作用范围改为组件本身。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

## Comments

### 实现记录（ticket 20）

- **作用范围**：改动单的 `scope` 为 `"usage" | "component"`。默认仍是这一处使用；推广后的改动 `scope: "component"`，`layer` 记为 `componentKey(loc)`（`component <元素位置>`），不是画布上的图层 id，所以按图层 id 查改动的地方（属性面板的断点标记、撤销、`changesOn` 等）都不会把它当成这一处使用的改动。
- **推广什么**：这个图层上未推广的样式改动（所有宽度与各断点的，断点保持不变）和生成说明，一起推广到使用链上离它最近的组件（`chain[0]`，即写出这个图层的组件）。结构改动、数据改动不推广。同一组件同一属性同一断点只有一条组件改动：从另一处使用再推广，并入那一条，保留最初的改前值；回到起点就不再是改动。没有并入的改动保留原编号，只改作用范围。
- **能推广的图层**（`inComponent`）：有元素位置、所在组件被用在另一个组件里（使用链长于 1），不是锁定图层、不是本轮新建的图层、也不是为了编辑而包上 `<span>` 的散文字。
- **画布**：组件改动写进组件在画布上所有元素（任一使用处，按元素位置找）的规则里一个单独的 `promoted` 块，排在这一处使用自己的改动之下，使用处的改动压过它。所有视图随画布同步。生成说明标记在组件的每个元素上，自己写了生成说明的使用处显示自己的。
- **之后再改**：推广后再改这个图层，从这一处使用开始，作为一条新改动，改前值是组件的值；改回组件的值就不再是改动。
- **撤销**：推广是一步撤销；从改动列表撤下组件改动、Discard all、预览模式下从保存的这一轮撤下（`revertSaved`），都把组件的所有使用处恢复原样，使用处自己的改动保留。
- **选中工具条**：单选一个画布上的图层时，在最后按下的视图（或桌面视图）里，选中框右上角、选中框上方 12px 处（避开生成说明的角标）；按钮样式同新 Frame 的 Brief 按钮，颜色用 `--vk-instance`，图标是 Tabler `arrow-bar-to-up`。第一版只有 Promote，没有按钮时不显示；`SelectionToolbar` 里给第二版的 States 留了位置（注释，排在第一位）。拖动、调值、播放、打字时隐藏。
- **改动说明**：组件改动的 Scope 写"The component itself: Card. Change Card where it writes the layer, at Location (`…`)…"，并写出它是从哪一处使用推广来的；使用处在组件生成说明之外另写的生成说明，写明它取代了组件的生成说明。改动列表的组件改动后标"· Card itself"。
- **Skill**：Scope 一节加了 **The component itself** 与 **Change it where it is written**；"Change exactly the scope given" 改为明确：这一处使用只改这一处，组件本身改组件；同一属性既有组件改动又有使用处改动时两者都要落地。
- **核对（`done`）**：组件改动在真实页面上核对组件的所有使用处，同一属性同一断点有自己改动的使用处除外（那里显示的是使用处的值）。
- 测试：`test/promote.browser.test.ts`（编辑命令接缝，12 个）、`test/cli.test.ts`（改动说明，2 个）、`e2e/tests/promote.spec.ts`（主接缝，3 个）。

### 已知限制

- 在断点上把流式布局里的图层改为自由定位、且它的容器因此成为定位参照的那条样式改动（`within`），以及要求代码给散文字包 `<span>` 的那条（`wrap`），不推广：它们依赖这一处使用的容器与画布上的包裹。这类图层上的其他样式与生成说明照常推广。
- 推广之后才复制的组件实例，复制时把当时的外观（包括组件改动）固化在副本上；之后撤销推广，副本仍显示组件改动的样子（改动单正确）。
- 使用处在组件生成说明之外另写的生成说明，改前值记的是当时组件的生成说明；之后组件的生成说明被撤下，这条使用处改动的改动说明仍提到它。
- 组件某断点上的值与使用处在所有宽度上的值同时存在时，画布上该断点显示组件的值（断点规则排在后面）；核对只跳过同一断点上有自己改动的使用处。
- 推广只在组件被用在另一个组件里时可用；服务端组件等使用链为空的图层不出现推广按钮。
