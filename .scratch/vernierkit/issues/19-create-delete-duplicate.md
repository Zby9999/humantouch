# 19: 新建、删除与复制

**What to build:** 设计师按 T / F 在画布上拖出文字图层或 Frame，插入位置遵循拖拽规则；新文字默认使用页面正文样式，新 Frame 默认固定尺寸、无填充。Frame 可附生成说明，内部可放草图图层，落地前显示为带说明文字的占位框。双击文字可直接修改内容。可删除图层，用 ⌘D 或 ⌥ 加拖动复制图层；对实例删除或复制时标为数据改动。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。

## Comments

**实现记录（2026-10-27）**

- 改动单（`changeset.ts`）：`Change.kind` 多了 `"create"`（新建文字或 Frame，`after` 是 `Created`：类型、位置 `place`、画出的宽高、文字内容或生成说明）、`"text"`（改文字，`before` / `after` 是文字）、`"delete"`（`before` 是原来的 `Place`）、`"duplicate"`（`target` 是被复制的图层，`before` 是它的位置，`after` 是副本的位置）。
  - 新建与复制沿用 17 的"新图层"一套：元素带 `data-vk-made`，之后对它（以及副本里每一层）的改动 `Target.made` 指向它，改动说明的位置写 "New: the layer is made in change N"，`done` 不核对；改动列表里单独撤回新建或复制时，连带撤回对它、在它里面、移入移出它的改动（`withDependents`，`madeBy` 认 `create` / `duplicate`）。
  - 新文字的内容、新 Frame 的生成说明写在新建这条改动里（改它们是更新这条改动，不另记一条）。
- 编辑命令（`edits.ts`，画布操作在 `layer-changes.ts`，编辑中的画布与保存的本轮共用）：
  - `create(type, to, size?)`、`canHold`：放进 Stack 的第几个，或 Frame 中的 X / Y（自由定位，Frame 未定位时设为定位参照）；在容器的每个实例里各放一个。新文字是 `<p>`，写入页面 `body` 的字体、字号、字重、行高、字距、颜色和 `margin: 0`（"页面正文样式"），内容为 "Text"；拖出宽度时宽度固定、高度随文字，单击则宽度随文字。新 Frame 是固定宽高、无填充的 `<div>`，单击为 100 × 100。
  - `brief` / `setBrief`：只有新建的 Frame 有生成说明（任意图层上的生成说明是 33）。
  - `setText`、`ownElement`：同一使用处各实例的文字相同时一起改；各实例文字不同时（循环渲染、文字来自数据），只改这一个，记为数据改动（属性名 `text-N`，元素记 `data-vk-text`）。**这是在规格之外补的**：规格只对删除、复制写了"数据改动"，但卡片标题这类文字改一处就改全部会出错。画布上恢复原文字时用 `data-vk-original-text` 记下的原内容（含加粗、链接等）。
  - 混排的裸文字改文字或删除时先包一层 `<span>`（15 的做法），这次给 `<span>` 带上容器的源码标记和 `data-vk-wrap`（第几段裸文字），之后对它的改动能定位到容器的源码（原来包过之后再改会变成"未定位"），各实例里的同一段裸文字仍归为一组。
  - `remove`、`canRemove`：画布上隐藏并记 `data-vk-deleted`，图层模型跳过它（不再是图层），撤销时恢复。循环渲染的实例只删这一个，记为数据改动（`delete-N`）。删除本轮新建的图层等于撤回新建（源码里本来没有它）；删除新合成的 Stack 时撤回合成，再删除其中的图层。
  - `duplicate(layer, to?)`、`canDuplicate`：副本放在原图层之后，或拖到的位置（与移动相同，位置按"其他图层中的第几个"）；在容器的每个实例里各复制一个；循环渲染的实例只复制这一个，记为数据改动。副本是本轮新建的图层：去掉原图层的图层 id、移动标记等，"原样式"记为复制时的样子，删掉的部分不复制。
  - 循环渲染的实例删掉一个后，其余实例仍按页面上的实例数计（删掉的仍在页面上），改动说明里仍是 "one of the 3 instances"。
- 界面：
  - T / F（与 Figma 相同）选文字或 Frame 工具，光标变十字；在画布上拖出（或单击）后按拖拽规则放入（`drag.ts` 的 `findPlace`：起点下最深的、能放图层的 Stack 或 Frame），工具随即复原；Esc 取消工具。新文字立即进入文字编辑，"Text" 全选。
  - 双击已选中的文字图层进入文字编辑：画布元素 `contenteditable="plaintext-only"`，回车、Esc 或焦点离开时结束，按编辑命令改文字（可撤销）。
  - Delete / Backspace 删除选中图层；⌘D 复制；拖动松手时按住 ⌥ 则在落点放一个副本、原图层不动。
  - 属性面板：新建的 Frame 有 Brief 一栏（文本框，离开时生效）。画布上新 Frame 显示为虚线占位框，有生成说明时框里显示说明文字（画布自带的样式表，不保存、不进参考样式）。
- 改动说明：种类 New text / New Frame / Text / Delete / Duplicate。新建写内容、大小和位置（文字要求用页面已有的正文样式）；新 Frame 有生成说明时另列 "Brief" 和 "Sketch"（画在其中的图层：文字、X / Y、宽高、对应的改动编号），画在这种 Frame 里的图层自己那一节注明"是草图，按生成说明落地"；改文字写原文与新文；删除写从哪个容器的第几个删掉；复制写副本放在哪里。数据改动按种类说明改数据的方式（改文字、删去条目、添加一条副本），数据来自代码之外时要求在报告中说明。改动列表显示如 "New text · Stack  “Hello”"、"Text · Vernier Kit  “Vernier Kit” → “Vernier”"、"Duplicate · Card  copy in Grid, 3rd"。
- Skill：新种类与 Brief / Sketch 的说明；新文字、新 Frame（生成说明用项目已有组件与风格、按草图布局，并在报告中说明做了什么）、改文字（保留加粗等片段；文字来自 prop 或变量时在给出处改）、删除与复制、数据改动（写在代码里则改，来自外部数据源则报告）的落地规则。
- 改动预览与核对：这些都计入 "N changes show once applied"，`done` 返回 "unchecked"；其中删除的预览、核对在 27。
- 测试：辅接缝 1 `edits.browser.test.ts`（Stack 中新文字的位置与正文样式、Frame 中自由定位的新 Frame 与定位参照、各实例一起新建、生成说明与草图及连带撤回、能否放入；改文字的各实例同改与改回、循环实例的数据改动、裸文字、新文字的内容、撤回后恢复加粗等片段；删除与撤销、循环实例单独删除与保存的本轮、删除新图层即撤回、删除新 Stack 连同图层；复制到原图层之后及副本是独立的新图层、循环实例的数据改动、拖到 Stack 或 Frame 中的复制与保存的本轮）；命令行接缝（新建与生成说明、草图、改文字与数据改动、删除与复制）；主接缝新增 `create.spec.ts`（T 拖出新文字并输入、F 在 Frame 空白处拖出自由定位的 Frame 与生成说明占位、双击改文字与 ⌘Z、Delete 与 ⌘D 复制循环卡片、⌥ 拖动复制、预览模式中计入"落地后可见"），`claim.spec.ts` 新增删除与复制循环卡片的数据改动和合成 Stack 的改动说明。

**已知限制**

- 文字编辑时不能用鼠标在文字中定位光标（画布不接收鼠标），只能用键盘；改文字后画布上该图层的加粗等片段变成纯文字，撤回后恢复。
- 换行（⇧回车）不支持，回车结束编辑。
- 新文字在 Stack 中的位置按拖拽起点算；在会拉伸子元素的 Stack 中，宽度随 Stack 拉伸。
- 副本放在原图层之后时，若原图层是自由定位，副本与它重叠在同一位置。

**代码审查后的修正（2026-10-27）**

- 改动说明的 "Sketch" 按图层现在的样子列出：画出后又改了 X / Y 或宽高的，用最新的值；移入或复制进这个 Frame 的图层也列出（"Button (moved in)"、"(a copy)"）。原来只列画出时的位置，会过时。
