# 19: 新建、删除与复制

**What to build:** 设计师按 T / F 在画布上拖出文字图层或 Frame，插入位置遵循拖拽规则；新文字默认使用页面正文样式，新 Frame 默认固定尺寸、无填充。Frame 可附生成说明，内部可放草图图层，落地前显示为带说明文字的占位框。双击文字可直接修改内容。可删除图层，用 ⌘D 或 ⌥ 加拖动复制图层；对实例删除或复制时标为数据改动。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。
