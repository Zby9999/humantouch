# 115: 编辑层直接写进源码：Tailwind 写死的类和 JSX 里写死的文字

**What to build:** 照 ADR 0015：改动列表里有一个按钮（例如「Write 3 simple changes」，措辞作为代定），设计师按一下，这一轮里简单的改动由编辑层直接写进源码，不等 Agent；剩下的照旧交给 Agent。这张只做两种：图层自己 JSX 里 className 字符串字面量中的 Tailwind 类（换掉、加上、去掉一个类，含 `md:` 这类断点前缀），和 JSX 里写死的一段文字。值从变量、props、数据或 `cn()`、带 `${}` 的模板字符串这类表达式里来的，结构性改动，实例上只作用于这个使用处的改动，都不算，交给 Agent。

建议的做法（作为代定，开线时定）：让编辑层走和 Agent 一样的一轮，只认领这几条，写，照 `done` 核对，归档；这样认领时的代码快照、`last` 撤回、核对、归档都不用另做一套，剩下的照 ADR 0013 留在同一张画布上。

参考本功能的 spec.md（同目录上一级，「交给 Agent 落地」「改动说明」「核对」「撤销上一轮」），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（ADR 0002、0005、0006、0013、0015）。
