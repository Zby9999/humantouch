## Comments

**实现记录（2026-10-29）**

- 吸附（`snap.ts` 的 `snap`，纯函数）：拖动的图层在 Frame 里自由定位时，每个方向分别吸到兄弟图层和 Frame 内框（边框以内）的起点、中线、终点，或者吸到与同一行（另一方向上有重叠）兄弟图层之间相同的间距：接在最近一个后面、排在最近一个前面，或者落在两者正中。取离得最近的位置，距离不超过屏幕上 5px（`SNAP_PX / 缩放`），所以在任何缩放下手感一样。吸附到的位置精确到 0.01px（与对齐对象完全对齐），没吸附的方向仍取整。Stack 里重排不吸附，因为位置由 Stack 决定（Figma 的 auto layout 也是这样）。
- 标记（`Mark`，画在视图上方）：红线表示对齐的边或中线，线的长度覆盖拖动图层和所有对齐对象；品红线加数值标签表示相等的间距（拖动图层两侧的间距，以及同一行里与之相等的间距）；⌥ 测距用红线加标签，图层不在同一行或同一列时，用虚线把对方的边延长到测量线所在的高度。所有标记按屏幕坐标绘制，线宽 1px、标签字号 11px，不随缩放变化。只画在拖动或悬停所在的那个视图里（`data-view`）。GLOSSARY 中 Guide 指安装说明，所以代码里叫 Mark，不叫 Guide。
- 拖动（`drag.ts` 的 `findDrop` 多了 `snapWithin`，`Drop` 多了 `box`、`marks`）：落到 Frame 的位置按吸附后的框计算。从画布外拖回视图（null 分支）同样吸附。按住 ⌘（Ctrl）不吸附；拖动过程中按下或松开 ⌘，不移动指针也会立即重算（`redrag`）。在平板、手机视图里拖动时，按该视图的排版吸附，结果按 37 的断点规则记录。
- ⌥ 测距（`snap.ts` 的 `distances`）：选中图层后按住 ⌥ 悬停，测量从选区（多选时取所有选中图层的外框）到点击会选中的那个图层的距离。悬停在选区本身上或没有别的图层时，测到最后选中图层的父容器，并给父容器描出轮廓。两者在某个方向上分开时，量两者之间的空隙；互相包含或重叠时，量两侧对应的边。距离为 0 的边不画。
- 微移（`Editor.nudge`，Shell 里的方向键，1px，按住 ⇧ 为 10px，有 ⌘ 或 ⌥ 时不触发）：
  - 自由定位的图层（在当前视图里是绝对定位的）：X、Y 加上偏移，走与拖动相同的 `move` 路径。页面原本就自由定位的图层改 X / Y；本轮移进 Frame 的图层更新那一条移动改动；在平板、手机视图里写成该断点的 X / Y（37）。
  - Frame 流式布局里的图层：先在原位变为自由定位，再加上偏移，和拖到 Frame 里的效果一样。
  - Stack 布局里的图层：沿 Stack 方向按方向键，与那一侧相邻的图层换位置（Figma 的做法），⇧ 也只换一位；到头或者垂直于 Stack 方向按，则不动。多选的相邻图层一起移动，最前面的一个到头就都停下。记为一条移动（重排）改动，在所有视图里生效（结构改动）。
  - Grid 里的图层和页面本身不动（Grid 是 18 的范围）。画布外的图层本身被选中时，在工作区里移动（每按一次是一步撤销）。
  - 合并：同一批图层的微移，前后两次相隔不到 1 秒（`NUDGE_RUN_MS`），算作同一轮，合成一步撤销（`Step.run`：依次串起每一步的撤销和重做，因为一轮里可能先改 X、再改 Y、再换位置）。改动单本来就按"图层 + 属性"只保留最初值和最终值，所以一轮微移在改动单里是一条 X、一条 Y，或者一条移动。撤销或重做之后再微移，算新的一轮。
- 测试：纯函数接缝 `snap.test.ts`（边、中线、取最近、间距在前/后/正中、不在同一行的图层不参与、DOMRect 式的 getter 盒子、超出范围不动，以及五种测距）；辅接缝 1 `edits.browser.test.ts`（自由定位微移并一步撤销、分开的微移分步撤销、Stack 内换位、到头不动、横向不动、多选一起移动、Frame 流式布局里的图层先变为自由定位、页面本身不动、其他图层的微移单独成步、手机视图里的断点微移与 Stack 换位）；主接缝 `e2e/tests/snapping.spec.ts`（吸到边并显示 1px 红线、⌘ 不吸附且中途按下松开立即生效、等间距品红标注和数值、平板视图里吸附并只在该视图画标记、画布外拖回时吸附、⌥ 测距到相邻图层和父容器、多选测距、方向键改 X / Y 并一步撤销重做、Stack 内换位为一条 Reorder、手机视图微移只在该断点生效）。

**已知限制**

- 绘制新图层（F / T 工具拖出的框）不吸附。
- 吸附只看同一 Frame 里的兄弟图层和 Frame 本身，不看更远的图层。
- 等间距的"同一行"按吸附前另一方向的位置判断：如果另一方向的吸附把图层移出了那一行，位置仍然吸到等间距，但不画品红标注（边缘情况）。
- 画布外的图层本身微移时，每按一次是一步撤销，不合并。
- 反向的 Stack（`row-reverse`、`column-reverse`）里，方向键按 Stack 的顺序换位，与看到的左右方向相反。
