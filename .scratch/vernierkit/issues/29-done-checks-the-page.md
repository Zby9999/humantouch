# 29: `done` 时核对改动

**What to build:** Agent 运行 `done <编号>` 时，编辑层撤下这条改动的预览，在真实页面上读出这个图层这项属性的值（所有实例），与改后值比较，结果回到 `done` 的输出：页面显示了这条改动；页面没有显示（附实际的值，提示按来源查明原因、修好后再运行一次 `done`）；或没能核对（没有打开的页面、图层此刻不在页面上、未定位）。等开发服务器热更新最多约 2 秒。核对结果随本轮归档，`finish` 列出没有显示出来的改动。

参考本功能的 spec.md（同目录上一级，"核对"一节），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策，尤其是 ADR 0006。

**Blocked by:** 26, 28

**Status:** ready-for-agent

- [ ] 源码改对了时，`done` 说明页面显示了这条改动
- [ ] 修改被别的样式盖住时，`done` 说明页面没有显示，并给出页面上实际的值
- [ ] 修好后再运行一次 `done`，重新核对
- [ ] 没有打开的页面时，`done` 不等待，照常记进度并说明没能核对
- [ ] 核对结果随本轮归档；`finish` 列出最后一次核对没有显示出来的改动
- [ ] Skill 补充：读 `done` 的输出，没显示出来时先修好再继续
- [ ] 主接缝：示例项目中真的改源码，一次改对、一次被 `index.css` 的规则盖住，断言 `done` 的输出与归档
