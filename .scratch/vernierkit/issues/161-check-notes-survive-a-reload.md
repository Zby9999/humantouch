# 161: 核对时第一次看到的挪动，页面重新加载后还在

**What to build:** ticket 146 让核对比较画出来的样子（ADR 0016）。它有两种做法：一是临时给页面加上画布的样式，看画面变不变；二是用第一次看时记下的挪动，认出「换一种写法、加起来一样」的改动，比如用 gap 代替 margin。做法二的记录现在只在页面内存里，页面一重新加载就没了。没了以后只剩做法一，这类换写法的改动会判成没显示。Next.js 改了某些代码会整页重新加载，Agent 落地时也可能刷新页面。

要做到：做法二的记录写进 `.humantouch/`，跟着这一轮的 claim 走，页面重新加载后还在。这一轮结束时，和别的这一轮的文件一起删掉（像 ticket 82 的 otherUsages）。记录对不上现在的页面时（实例个数、顺序变了），照旧不用，判没显示，不出虚假的 ✓。

用词以 GLOSSARY.md 为准，涉及 ADR 0016。测试只跑相关的部分，整套由规划会话在 main 上按批跑。
