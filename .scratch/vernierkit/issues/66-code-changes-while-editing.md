# 66: 编辑中代码在变时先暂停

**What to build:** 编辑模式中，没有 Agent 认领改动单，页面却因为项目源码变化而热更新时（例如 Agent 没走 Skill、凭对话直接改了代码），编辑层暂停编辑，提示设计师「代码在变，但没有 Agent 认领改动」，给两个选择：继续编辑（这次变化与我的改动无关），或回到预览模式（改动保留，下次进入编辑模式回到同一张画布）。不影响页面的文件变化、编辑层自己的保存都不触发提示。

参考本功能的 spec.md（同目录上一级），目标与指标以 docs/goals.md 为准，用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（ADR 0005、0012）。

## 背景

- ADR 0005 靠认领避免画布和代码冲突，但前提是 Agent 走了 Skill。没认领就改代码时，画布已过期，设计师接着改会和代码冲突。
