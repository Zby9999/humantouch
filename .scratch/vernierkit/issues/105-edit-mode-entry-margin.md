# 105: 进入编辑模式找回余量：建图层树挪到进场动画期间

**What to build:** 大页面（5006 个元素、三个视图）上进入编辑模式的目标是 16 次的中位数 ≤ 150ms（ticket 22）。发布前的有窗口验收（2026-11-05，ticket 22「第十轮」）：全套那次 157.6ms 没达标（其中一次 673ms），单独重跑两次 146.5、146.0ms 达标；页面刚载入后第一次进入在 158ms 上下，已经超过 150ms，而这正是设计师每次刷新页面后最常碰到的那一次。第九轮还是 130.7、139.3ms，之后加了 97、99、104 等，余量从十几毫秒缩到 4 毫秒左右。往后每加一个功能都可能超标。

要做到：照设计师在 ticket 22 第三轮预先同意的办法，把建图层树（约 29ms）和 Layers 面板的第一次渲染挪到进场动画期间做。代价：Layers 面板的内容在动画开始后几帧才出现，动画结束前一定出来。进入编辑模式（到桌面视图那一帧画出来）的中位数回到 150ms 以内、留出余量，首次进入也在 150ms 以内。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策（ADR 0011）和 ticket 22 里设计师对性能的回答。

**Blocked by:** 无（发布以后再做，见「设计师决定」）

**Status:** ready-for-agent

- [ ] 建图层树和 Layers 面板的第一次渲染挪到进场动画期间；Layers 的内容在动画结束前一定出来；进场动画本身、画布、三个视图的样子不变
- [ ] 进入编辑模式时马上按键、点 Layers、选图层（动画还没结束）都照常起作用，不丢操作
