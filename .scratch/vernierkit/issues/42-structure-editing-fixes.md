# 42: 结构编辑的验收修正

**What to build:** 设计师验收 17、19 时发现的问题：

1. Stack 改了方向后，拖拽的落点与让位仍按原来的方向计算。拖拽应按 Stack 此刻实际的排列方向。
2. 合成 Stack 时保留了子图层的外边距：间距显示为 0，子图层之间却有空隙，Hug 也把外边距包了进去。合成时把子图层之间的外边距并入推断出的间距，子图层的外边距清零；最外侧的外边距移到新 Stack 自己身上，画面不跳。属性面板上看到的间距就是实际的间距。
3. 新建的 Frame 显示为普通的空 Frame（无填充、无虚线、框内不显示说明文字），之后还可以在里面编辑；生成说明只在属性面板中编辑，图层树中有生成说明的 Frame 带一个标记。
4. 文字编辑状态按 Framer 的样子：进入编辑时文字框的边框变为蓝色、选区为蓝色。
5. 工具栏：右上角贴着属性面板，放"选择（V）""Frame（F）""文字（T）"三个工具，显示当前工具，点击切换，与快捷键一致。

参考本功能的 spec.md（同目录上一级），用词以 GLOSSARY.md 为准，并遵守 docs/adr/ 中的决策。
