## 打字时鼠标在文字里可用（11-08，子 agent 做，已合回）

- 打字时，在正在编辑的文字里：
  - 单击放光标，按住 Shift 单击可以扩展选区；
  - 拖动选中文字；
  - 双击选一个词；
  - 三击选中这个文字图层的全部文字。
- 点到文字外面还是结束打字，Enter、Esc 也一样。平移、缩放不受影响。
- 做法：在画布 viewport 的 `onPointerDown` 里，把落在正在编辑的文字上的点击转给文字处理；不让点击直接穿到 iframe，因为那样文字上方就没法平移和缩放了。
- 文件：`CanvasView.tsx`；测试：`create.spec.ts` 新增 3 条。
- 和浏览器不完全一样的地方（子 agent 报的，等设计师看）：
  - 三击选中全部文字，不是一行；只有文字里用 Shift+Enter 换过行时才看得出区别。
  - 双击或三击之后接着拖动，选区不会按词扩展。
  - 在别的视图里点到同一段文字，还是会结束打字。

## 修好的问题

- **填进去的尺寸被改成别的值**（11-08，设计师发现）：比如 Width 填 139.74，显示成 139.73，再填一次还是 139.73。
  - 原因：浏览器排版时把尺寸对齐到 1/64 像素，139.74 实际排成 139.734375；面板显示的是排出来的尺寸。
  - 改法：读 Fixed 尺寸时，如果页面上写的像素值和排出来的尺寸只差这一点对齐误差（不到 1/32 像素），就用写的值；面板上 Fixed 的数字显示读到的这个值，不再显示量出来的框宽。差得更多时（比如被 min/max 卡住了），还是用排出来的尺寸。
  - 影响：改动记录里的 before/after 也按写的值记。这是修 bug，不是样式改动。
  - 文件：`property-table.ts`（`size` 的 `read`）、`Properties.tsx`（`SizeRow`）；测试：`layout.spec.ts` 新增一条。
